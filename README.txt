# ஆயிரம் உணர்வுகள்… 24 காரணங்கள்!

A standalone, mobile-friendly scratch-card website.

## Preview locally
Open `index.html` in a modern browser. Keep the `images` folder beside it.

## Publish with GitHub Pages
1. Create a **new, separate GitHub repository** for this gift website.
2. Upload `index.html` and the complete `images` folder (keep the filenames 01.jpg through 24.jpg).
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the Pages URL to appear. The QR code should be created only after that live URL is confirmed.

The scratch layer covers the poem text in the upper part of each image. The illustration remains visible below it. Scratch with a finger on mobile or a mouse on desktop. The final letter appears after all 24 cards are revealed.
